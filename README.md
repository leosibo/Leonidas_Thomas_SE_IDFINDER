# ID Finder Rwanda · Milestone 3

**UNILAK Rwamagana Campus**  
Software Engineering and User Centred Design

- MISIGARO Thomas (M04930/2025)
- SIBOBUGINGO Leonidas (M04070/2025)

We designed a mobile-friendly prototype for reporting found identity documents and searching for a possible match. The finder receives a report reference after submitting. The ID owner can search by name or exact ID number. A match displays the document type, general found area and reference. The finder’s phone number, full ID number and uploaded photo stay private in the proposed system.

## Try the prototype

[Open the clickable Figma prototype](https://www.figma.com/proto/lgxGv1sbcZf3BsEp7e2Ixu?node-id=1-8&starting-point-node-id=1%3A8)

1. Select **Report a found ID**, attach the sample photo, review the report and submit. The confirmation shows **IDF-0001**.
2. Select **Search for my ID** and search for **Demo Owner** or **DEMO-0001** to see a possible match.
3. Choose **Unlisted Owner** to see the no-match message and try another search.

The prototype uses preset examples to simulate uploads, submissions and searches.
